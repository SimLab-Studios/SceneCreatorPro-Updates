# SceneCreator Pro Updates

Official software update distribution for SceneCreator Pro.

SceneCreator Pro 1.3.5 and later can check for updates through **Help > Check for Updates**, or automatically when the application starts. Installation always requires your approval.

Release downloads are verified and assembled automatically by the application. The download parts in a release are not separate installers and should not be run individually.

This repository contains release information and distribution files. It does not contain the application source code. Third-party license notices are included with the software.
